# 附錄：MVP 驗收標準

## 功能驗收

| 項目            | 驗收標準                     |
| ------------- | ------------------------ |
| PDF 上傳        | 可成功上傳並建立 document record |
| 圖片上傳          | 可成功 OCR 並建立 chunk        |
| PDF 解析        | 文字型 PDF 可直接抽取            |
| 掃描 PDF        | 可進入 OCR 流程               |
| Embedding     | 可呼叫本地 embedding 服務       |
| Vector Search | 可依問題找出相關 chunk           |
| 問答            | 可根據 retrieved context 回答 |
| Citation      | 回答包含文件、頁碼、章節             |
| 權限            | 無權限使用者無法檢索文件             |
| DLP           | API key、IP、客戶名稱等可遮罩      |
| Audit         | 問答、檢索、遮罩、LLM 呼叫都有紀錄      |

## 品質驗收

| 項目    | 驗收標準                 |
| ----- | -------------------- |
| 回答忠實性 | 回答不可明顯超出來源文件         |
| 來源正確性 | citation 能對應實際 chunk |
| 檢索準確率 | 測試問題 top-k 能命中正確文件   |
| 遮罩召回率 | 重要敏感資訊不可漏遮           |
| 權限防護  | 不可透過問答取得未授權資料        |
| 錯誤追蹤  | 每次錯誤可由 request_id 追蹤 |
